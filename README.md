# 신규 비금융(대안정보) 데이터가 신용위험 예측력을 높이는가?

> 금융 이력이 부족한 고객(씬파일러)의 신용을 비금융 데이터로 얼마나 보완할 수 있는지, 통계 검증과 랜덤포레스트 모델링으로 확인한 팀 프로젝트입니다. 이 저장소에는 **제가 맡은 파트의 코드만** 정리했습니다.

## 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 주제 | 신규 비금융 데이터(대안정보) 발굴과 신용위험 예측 기여도 검증 |
| 기간 | 2개월 (`[2026.07 ~ 20262.08]`) |
| 형태 | 팀 프로젝트 (`[4]명`), 부트캠프 과정 중 진행 |
| 데이터 | Kaggle [Home Credit Default Risk](https://www.kaggle.com/c/home-credit-default-risk) 기반 (아래 "데이터 안내" 참고) |
| 내 역할 | 랜덤포레스트(RF) 트랙 전담: 금융변수(A군) SQL 전처리, EDA, 가설검증(t-test), RF 모델링, 세그먼트 추가검증 |

## 연구 질문

- **RQ1**: 기존 비금융 변수(B군)를 금융 변수(A군)에 추가하면 예측력이 유의하게 오르는가? (M1 vs M3)
- **RQ2**: 신규 비금융 변수(C군)를 더하면 추가로 오르는가? (M3 vs M4, B군 효과는 M3에 이미 포함돼 통제됨)
- **추가 가설**: 금융이력이 없고(씬파일러) 나이가 적을수록 사회연결망 변수의 영향이 클 것이다.

## 변수 그룹

| 그룹 | 내용 |
|---|---|
| A 금융 | 소득·대출·Bureau(신용조회 이력) 기반 18개 변수 |
| B 기존 비금융 | 연령, 직업, 소득유형, 조직유형 |
| C 신규 비금융 | 자산, 자녀, 사회적 관계, 학력, 주거 (전체 15개 / 사회연결망 3개) |

## 사용한 방법

1. **전처리 (MySQL)**: 결측 처리 → 이상치 유지 → 파생비율(LTV, 소득 대비 대출 등) → 로그변환 → 인코딩 → Bureau 집계 후 LEFT JOIN
2. **EDA**: 그룹별 결측·분포·이상치·TARGET과의 관계 (그룹을 합치지 않고 독립 분석)
3. **가설검증**: Welch's t-test, Levene 등분산 확인, FDR(Benjamini–Hochberg) 보정, 효과크기(Cohen's d), IV 병합
4. **모델링**: 랜덤포레스트 M1~M4, 동일 train/test 분할 재사용(`random_state=42`), AUC 비교, DeLong test, 변수중요도
5. **추가검증**: 금융이력(씬/씩파일러) × 연령대 세그먼트별 5-fold OOF 평가, SHAP으로 사회연결망 변수의 영향 방향 분석

| 모델 | 입력 | 역할 |
|---|---|---|
| M1 | A | 금융정보만의 기준 성능 |
| M2 | B | 참고치 |
| M3 | A + B | RQ1 판정 |
| M4 | A + B + C | RQ2 판정 |

**도구**: MySQL 8, Python (pandas, numpy, scipy, statsmodels, scikit-learn, shap, matplotlib, seaborn), Google Colab
